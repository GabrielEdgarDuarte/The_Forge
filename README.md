# The Forge

A static website introducing beginners to blacksmithing: how smiths read the temperature of steel by its colour, the tools and techniques of a forge, the history of power hammers and a gallery of historical blades.

**Live site:** https://gabrieledgarduarte.github.io/The_Forge/

## Features

- **Hero:** full-screen opening with a forge glow and rising embers made with a CSS animation.
- **Reading the heat:** drag a slider to heat a steel bar and see its colour, temperature and what blacksmiths use that heat for.
- **Tools and techniques:** two carousels with arrow buttons, built from `data/tools.json`. Each technique card is coloured by its own colour from the data file.
- **Power hammers:** historical photos and a timeline from Roman water wheels to modern air hammers.
- **Museum:** historical swords fetched from [The Met Collection API](https://metmuseum.github.io/).
- Light and dark theme, remembered between visits.
- Smooth scrolling between sections and a responsive layout for phones and desktops.

Built with plain HTML, CSS and JavaScript, without any libraries.
