# The Forge

A static website introducing beginners to blacksmithing: how smiths read the temperature of steel by its colour, the basic tools and techniques of a forge, and a gallery of historical blades.

**Live site:** https://gabrieledgarduarte.github.io/The_Forge/

## Features

- **Reading the Heat:** drag a slider to heat a steel bar and see its colour and what blacksmiths use that temperature for.
- **Tools & Techniques:** cards loaded from `data/tools.json`, filterable by tools or techniques.
- **From the Museum:** historical swords fetched from [The Met Collection API](https://metmuseum.github.io/).
- Light and dark theme, remembered between visits.
- Responsive layout for phones and desktops.

Built with plain HTML, CSS and JavaScript, without any libraries.
